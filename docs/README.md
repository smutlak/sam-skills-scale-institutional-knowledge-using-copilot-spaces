# OctoAcme Project Management Documentation

Welcome to the OctoAcme project management knowledge base. This folder is the
central home for the processes, guides, and roles that OctoAcme teams use to
plan, execute, and continuously improve their work.

## Overview

OctoAcme runs projects with a lightweight, iterative approach centered on
customer value, clear ownership, and data-informed decisions. Every project
moves through a consistent lifecycle — from initiation and planning, through
execution and release, to retrospective and continuous improvement — with
defined roles and communication practices supporting the team along the way.

New to OctoAcme? Start with the
[Project Management Overview](octoacme-project-management-overview.md) for a
concise introduction to our principles, roles, and key artifacts, then explore
the process guides below in order or jump directly to the topic you need.
